## telegram直登号分两种，登录顺序完全相反

tdata 电脑直登号走另一条路。卖家发来一个压缩包，里面是 `tdata` 文件夹。你下载 Telegram 便携版（Portable version），解压后把 `tdata` 复制进去、替换目标文件，双击 Telegram 图标就自动登录，全程不输验证码。社区里的账号转换工具也能把协议号的 session 转成 tdata，说明它本质上是 Telegram 桌面端的一种登录数据格式，和账号本身的质量高低没有直接关系。

这里有个几乎没人提前说的细节：**tdata 的免验证码只发生在电脑端首次登录**。之后你想在手机上同步这个号，仍然要在手机端输入号码，然后回到已经登录的电脑客户端看那串 5 位验证码，填进手机。如果账号设了二次验证密码，压缩包里会有一个 2FA 文件，里面就是这串密码，手机端登录时要一并输入。买完第一件事就是把 2FA 密码改成自己的，否则上家随时能登回去。

两种直登号的首登顺序：

- 手机接码直登号：手机 APP 首登 → 接码网址取码 → 成功后再同步电脑端
